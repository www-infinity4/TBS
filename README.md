# TBS Superstation

A synchronized 1990s-inspired TBS-style channel built on the same Infinity TV scaffold as the other live channels.

Programming identity: classic Warner/Hanna-Barbera animation blocks, classic sitcoms and comedy, and Superstation movie windows at 6 PM, 8 PM and 10 PM. The live guide changes each viewer-local day at midnight while remaining deterministic for that day.
